# بوابة المصريين - Egyptians Gate

## نظرة عامة
بوابة المصريين هي نموذج موقع عربي مصمم لمساعدة الطلاب في استكشاف المنح الدراسية، الجامعات، والدول الدراسية.

## هيكل المشروع
- `index.html`: الصفحة الرئيسية وواجهة المستخدم.
- `styles.css`: الأنماط والتصميم.
- `data.js`: البيانات المستخدمة في الموقع مثل المنح والجامعات والمقالات.
- `app.js`: المنطق الوظيفي، إدارة الصفحات، البحث، والتصفية.
- `assets/images/placeholder.svg`: صورة بديلة تستخدم عند عدم توفر صور حقيقية.

## كيفية التشغيل محلياً
1. افتح المجلد `UWC [DO NOT ENTER]`.
2. افتح الملف `index.html` مباشرة في المتصفح.

> لا يتطلب المشروع تشغيل خادم محلي، ويعمل دون اتصال بالإنترنت.

## النشر
يمكنك نسخ جميع الملفات إلى أي خادم ويب ثابت أو استضافة ملفات مثل GitHub Pages.

## الاعتمادات
لا يحتوي المشروع على أي تبعيات خارجية. يتم الاعتماد فقط على ملفات CSS و JavaScript المحلية.

## الملاحظات
- تم تنظيف المشروع من أي اعتماد على خدمات خارجية أو مكتبات خارجية.
- تم تحسين التنقل، البحث، والمقارنة ليعملوا بشكل مستقل داخل صفحة واحدة.
